### 조건문 종류별 쓰임새

| 형태 | 쓰는 상황 |
|------|----------|
| `if` 단독 | 조건 맞을 때만 실행, 아니면 그냥 넘어감 |
| `if - else` | 둘 중 하나만 실행 ("이거 아니면 저거") |
| `if - elif - else` | 여러 경우의 수를 순서대로 처리 |
| 삼항 연산자 | 변수에 값을 바로 담을 때 (한 줄 처리) |

---

### 삼항 연산자

```python
# 형식: 참일 때 값 if 조건 else 거짓일 때 값
result = "합격" if score >= 60 else "불합격"
```

- `if - else`를 **한 줄**로 줄인 것
- 변수에 값을 바로 넣을 때 자주 사용
