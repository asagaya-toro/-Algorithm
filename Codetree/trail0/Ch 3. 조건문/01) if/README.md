조건문은 **"경우에 따라 다르게 동작해야 할 때"** 사용한다.

### 주요 활용 상황

| 상황 | 예시 |
|---|---|
| 입력값 검증 | 사용자가 올바른 값을 넣었는지 확인 |
| 분기 처리 | 로그인 여부, 권한 레벨, 상태값에 따라 다른 로직 실행 |
| 예외 방지 | 0으로 나누기, None 체크, 빈 리스트 접근 전 확인 |
| 비즈니스 로직 | 할인 조건, 등급 분류, 합격/불합격 판단 |
| 반복문 내 필터링 | 특정 조건에 맞는 항목만 처리 |

---

### 기본 문법

```python
if score >= 90:
    print("A")    # 조건이 True일 때만 실행
else:
    print("F")    # 조건이 False일 때만 실행
print("끝")       # 조건과 무관하게 항상 실행
```

- `if` 블록 → 조건이 **True**일 때만 실행
- `else` 블록 → 조건이 **False**일 때만 실행
- 들여쓰기 없는 코드 → **항상** 실행

---

### 🔴 들여쓰기 (Indentation)

파이썬은 들여쓰기로 코드 블록을 구분한다.  
`if` 조건이 **참(True)일 때 실행할 코드**를 들여쓰기로 표시하는 것.

```python
if score >= 90:
    print("A")    # ← 조건이 True일 때만 실행
    print("합격") # ← 같은 블록, 같이 실행됨
print("끝")       # ← 들여쓰기 없음 = 조건과 무관하게 항상 실행
```

> 들여쓰기는 **스페이스 4칸** 또는 **탭 1개**를 사용한다. (혼용 금지)

---

### 들여쓰기 오류 시 발생하는 에러

| 에러 | 발생 원인 |
|---|---|
| `IndentationError` | 들여쓰기가 아예 없거나 잘못된 위치 |
| `TabError` | 스페이스와 탭을 혼용 |
| `SyntaxError` | 불필요하게 들여쓴 코드 |
