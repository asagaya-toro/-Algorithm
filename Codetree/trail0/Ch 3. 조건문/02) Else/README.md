if-else 문은 **"경우에 따라 다르게 동작해야 할 때"** 사용한다.

### 기본 문법

```python
if score >= 90:
    print("A")  # 조건이 True일 때만 실행
else:
    print("F")  # 조건이 False일 때만 실행
print("끝")     # 조건과 무관하게 항상 실행
```

- `if` 블록 → 조건이 **true**일 때만 실행
- `else` 블록 → 조건이 **false**일 때만 실행
- 중괄호 밖 코드 → **항상** 실행
