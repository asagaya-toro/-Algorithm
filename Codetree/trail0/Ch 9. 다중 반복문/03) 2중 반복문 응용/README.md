### 구조 이해

```python
for i in range(3):        # 외부 반복문: 단(행)을 제어
    for j in range(3):    # 내부 반복문: 각 행 안의 반복을 제어
        print(i, j)
```

외부 반복문이 **1번** 실행될 때, 내부 반복문은 **처음부터 끝까지 전체**를 완주한다.  
총 실행 횟수 = 외부 횟수 × 내부 횟수

---

### 대표 활용 예

| 상황 | 설명 |
|------|------|
| 구구단 출력 | 외부: 단(2~9), 내부: 곱하는 수(1~9) |
| 2차원 배열 순회 | 외부: 행(row), 내부: 열(col) |
| 좌표 쌍 생성 | 외부: x축, 내부: y축 |
| 패턴/별 출력 | 외부: 줄 수, 내부: 한 줄의 문자 수 |
| 완전탐색 (브루트포스) | 모든 조합 (i, j) 시도 |

---

### ⚠️ 주의점

**1. 시간 복잡도가 급격히 커진다**  
외부 N번 × 내부 N번 = O(N²)  
N = 10,000이면 실행이 1억 번 → 입력 크기에 민감하게 설계해야 함

**2. `break`는 한 단계만 탈출한다**  
```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break   # 내부 반복문만 탈출, 외부는 계속 실행됨
```
내부·외부 동시 탈출이 필요하면 `flag` 변수나 함수화 후 `return` 사용

**3. 변수명 혼동 주의**  
`i`, `j` 대신 역할을 담은 이름(`row`, `col` / `dan`, `num`)을 쓰면 디버깅이 훨씬 쉽다

**4. 들여쓰기 레벨 착각**  
단과 단 사이 빈 줄(`print()`) 같은 코드는 내부 반복문이 아닌 **외부 반복문 레벨**에 넣어야 한다

```python
for dan in range(2, 10):
    for num in range(1, 10):
        print(f"{dan} x {num} = {dan * num}")
    print()   # ✅ 여기 (외부 루프 레벨)
              # ❌ 위 줄과 같은 들여쓰기면 매 곱셈마다 빈 줄이 생김
```
