### 1. "중첩 반복문 구조를 안다"와 "이 문제에 맞게 매핑한다"는 다른 능력
이중 for문 틀(외부 반복 → 내부 반복 → 줄바꿈/리셋 → 외부 복귀)은 익숙했지만,
**내부 반복문이 무엇을 위해 도는지**가 문제마다 다름.
- 기존에 익혔던 패턴: 내부 반복 = 출력/누적 출력용
- 이 문제: 내부 반복 = **어떤 판별을 위한 탐색**
