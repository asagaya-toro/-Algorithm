### 2중 반복문이란?

`for` 문 안에 `for` 문이 중첩된 구조.  
바깥 루프 1번 돌 때마다 **안쪽 루프가 처음부터 끝까지 전부** 돈다.

```python
for i in range(3):        # 바깥 루프: 3번
    for j in range(5):    # 안쪽 루프: 매번 5번
        print(i, j)       # 총 3 × 5 = 15번 실행
```

> 💡 총 실행 횟수 = 바깥 횟수 × 안쪽 횟수

---

### 다중 반복문이 필요한 이유

| 상황 | 예시 | 구조 |
|------|------|------|
| 2차원 데이터 | 행렬, 표, 게임 보드 | 행 × 열 |
| 조합 / 순열 | 모든 쌍 비교, 경우의 수 | 원소 × 원소 |
| 구구단 | 단 × 수 | 2~9 × 1~9 |
| 패턴 출력 | 별 찍기, 삼각형 | 행 × 열 |

---

| 코드 | 역할 |
|------|------|
| `end=""` | 자동 줄바꿈 제거 (같은 줄 이어서 출력) |
| `print()` | 행 끝에서 다음 줄로 이동 |
| `"* " * N` | 문자열 곱셈으로 반복 (안쪽 루프 대체 가능) |

---

## 주의할 점

> ⚠️ 중첩이 깊어질수록 실행 횟수가 **곱으로** 늘어남.  
> 3중 루프 → N³번. 백준에서 N=1000이면 10억 번 → **시간 초과!**

```python
# N=100 기준 실행 횟수 비교
# 1중:   100번
# 2중:   10,000번
# 3중:   1,000,000번  ← 여기서부터 위험
```
