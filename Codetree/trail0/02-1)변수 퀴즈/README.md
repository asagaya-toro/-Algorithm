### 1. 파이썬 기본 자료형 종류 요약

| 분류 | 자료형 | 기호/형태 | 특징 |
| :--- | :--- | :--- | :--- |
| 숫자형 | 정수형(int) | 숫자 | 소수점이 없는 양수와 음수 데이터 |
| 숫자형 | 실수형(float) | 소수점 | 소수점이 포함된 실수 데이터 |
| 시퀀스형 | 문자열(str) | `' '` 또는 `" "` | 따옴표로 감싸진 텍스트 데이터 |
| 시퀀스형 | 리스트(list) | `[]` | 대괄호를 사용하는 변경 가능한 데이터 목록 |
| 시퀀스형 | 튜플(tuple) | `()` | 소괄호를 사용하는 변경 불가능한 데이터 목록 |
| 매핑/집합 | 딕셔너리(dict) | `{}` | 중괄호를 사용하는 키-값 쌍의 데이터 |
| 매핑/집합 | 집합(set) | `{}` | 중괄호를 사용하는 중복이 없는 데이터 모음 |
| 논리형 | 불리언(bool) | `True` / `False` | 참과 거짓을 나타내는 데이터 |

- - -

### 2. 파이썬 자료형의 가독성 높은 구문 특징

#### 선언 특징
* 🔴 데이터 타입 명시 생략 가능
* 변수에 값을 대입할 때 자료형이 자동으로 결정

#### 데이터 제어 특징
* 🔴 리스트 내부에 서로 다른 자료형의 혼합 저장 가능
* 딕셔너리를 활용한 구조화된 데이터 관리 용이
