# 파이썬 print() 함수 특징 요약
1. 파이썬 print()가 간결한 이유
인터프리터 구조 기반: 메인 함수(main) 선언 과정 생략
인터프리터 구조 기반: 필수 배경 코드 생략
자동 타입 변환 지원: 데이터 종류와 관계없이 내부에서 자동 변환 후 출력
출력 기능 내장: 출력 후 자동 줄 바꿈(\n) 처리
출력 기능 내장: 데이터 간 공백 분리 기능 제공

2. Python 특징 및 구문 복잡성 비교
Python 문법 코드: print("Hello")
직관적인 문법: 코드 읽기와 작성이 매우 직관적임
구문 간소화: 세미콜론(;) 생략 가능
구문 간소화: 데이터 타입 명시 생략 가능

# 인터프리터(Interpreter) 란
1. 인터프리터의 개념
실시간 번역기: 코드를 한 줄씩 읽어가며 즉시 실행하는 프로그램
실행 방식: 소스 코드 전체를 미리 컴퓨터용 파일로 바꾸지 않고 실행 시점에 번역
작업 효율: 코드를 수정하고 저장하면 빌드 과정 없이 곧바로 결과 확인 가능

2. 컴파일러와의 비교
컴파일러: 소스 전체를 기계어 파일(.exe)로 한 번에 번역 후 실행 (C, Java 등)
인터프리터: 별도의 기계어 파일 생성 없이 실시간 변환 후 실행 (Python, JavaScript 등)
속도 특징: 실행 준비 속도는 빠르지만 대량의 연산 처리 속도는 상대적으로 느림
