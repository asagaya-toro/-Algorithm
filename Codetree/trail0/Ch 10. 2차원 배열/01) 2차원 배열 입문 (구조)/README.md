### 파이썬 2차원 배열 구조

파이썬의 2차원 배열은 **엑셀 시트**와 같은 구조다.

| 엑셀 | 파이썬 2차원 배열 |
|---|---|
| 가로줄 (행) | `arr[i]` |
| 세로줄 (열) | `arr[i][j]` |

```python
arr = [
    [1, 2, 3],   # 0행
    [4, 5, 6],   # 1행
    [7, 8, 9]    # 2행
]
```

|       | 열0 | 열1 | 열2 |
|-------|-----|-----|-----|
| **행0** | 1   | 2   | 3   |
| **행1** | 4   | 5   | 6   |
| **행2** | 7   | 8   | 9   |

- `arr[i]` → i번째 행 전체
- `arr[i][j]` → i번째 행의 j번째 칸 값
- 인덱스는 0부터 시작

예: `arr[1][2]` → 1행 2열 → `6`
