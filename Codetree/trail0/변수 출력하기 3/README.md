### 3. 파이썬 출력 함수 & f-문자열 정리

---

#### print() 주요 매개변수

| 매개변수 | 기본값 | 역할 | 코드 예시 | 실행 결과 |
| :--- | :--- | :--- | :--- | :--- |
| `sep` | `" "` (공백) | 값 사이 구분 문자 지정 | `print("a", "b", sep="-")` | `a-b` |
| `end` | `"\n"` (줄바꿈) | 출력 끝에 붙는 문자 지정 | `print("hello", end="!")` | `hello!` |

---

#### 이스케이프 문자

| 문자 | 의미 | 코드 예시 | 실행 결과 |
| :--- | :--- | :--- | :--- |
| `\n` | 줄바꿈 | `print("a\nb")` | a 출력 후 줄바꿈 후 b |
| `\t` | 탭 간격 | `print("a\tb")` | `a    b` |

---

#### f-문자열 기본 구조

- 문자열 앞에 `f` 를 붙이고, 변수나 표현식은 `{}` 안에 작성
- `{}` **밖** → 문자 그대로 출력 / `{}` **안** → 파이썬이 평가 후 출력

```python
name = "a"
f"안녕, {name}!"   # 안녕, a!
f"name"            # name  ← 중괄호 없으면 문자 그대로
```

- 🔵 **중괄호 자체를 출력하려면 `{{` `}}`로 두 번 작성**

```python
f"{{name}}"   # {name}
```

---

#### 🔵 f-문자열 서식 지정

서식 순서: `{ 값 : 채울문자 정렬방향 전체자릿수 . 소수점자릿수 f }`

| 기능 | 코드 예시 | 실행 결과 |
| :--- | :--- | :--- |
| 변수 삽입 | `f"{name}"` | `혜진` |
| 표현식 | `f"{2 + 3}"` | `5` |
| 함수 호출 | `f"{len('hello')}"` | `5` |
| 소수점 지정 | `f"{3.14159:.2f}"` | `3.14` |
| 왼쪽 정렬 | `f"{'hi':<10}"` | `hi--------` |
| 오른쪽 정렬 | `f"{'hi':>10}"` | `--------hi` |
| 가운데 정렬 | `f"{'hi':^10}"` | `----hi----` |
| 채울 문자 지정 | `f"{'hi':*>10}"` | `********hi` |
| 정렬 + 소수점 조합 | `f"{3.14159:>10.2f}"` | `------3.14` |
