### 1. 파이썬 산술 및 대입 연산자 요약 표

| 분류 | 연산 기호 | 코드 예시 | 실행 결과 특징 |
| :--- | :--- | :--- | :--- |
| 산술 연산 | `+` / `-` | `5 + 2` / `5 - 2` | 덧셈 결과인 `7` 및 뺄셈 결과인 `3` 반환 |
| 산술 연산 | `*` / `/` | `5 * 2` / `5 / 2` | 곱셈 결과인 `10` 및 나눗셈 실수 결과인 `2.5` 반환 |
| 산술 연산 | `//` / `%` | `5 // 2` / `5 % 2` | 나눗셈의 몫인 `2` 및 나머지 값인 `1` 반환 |
| 🔵 산술 연산 | `**` | `5 ** 2` | 거듭제곱 결과인 5의 제곱 값 `25` 반환 |
| 대입 연산 | `=` | `b = c` | 우변의 데이터 c를 좌변의 변수 b에 그대로 할당 |
| 복합 대입 | `*=` / `/=` | `b *= c` / `b /= c` | 기존 b 값에 c를 곱하거나 나눈 값을 다시 변수 b에 저장 |
| 증감 대입 | `+=` / `-=` | `b += 1` / `b -= 1` | 변수 b의 값을 1씩 증가시키거나 1씩 감소시켜 다시 저장 |

### 2. 파이썬 비교 및 논리 연산자 요약 표

| 분류 | 연산 기호 | 코드 예시 | 실행 결과 특징 |
| :--- | :--- | :--- | :--- |
| 비교 연산 | `==` / `!=` | `b == c` / `b != c` | 두 값이 같으면 `True` 또는 다르면 `True` 반환 |
| 비교 연산 | `>` / `<` | `b > c` / `b < c` | 크기 비교 조건 성립 여부에 따라 `True` 또는 `False` 반환 |
| 🔵 연쇄 비교 | `a < b < c` | `1 < b < 5` | 변수 b가 1보다 크고 5보다 작은지 두 조건을 동시에 비교 |
| 논리 연산 | `and` | `b and c` | 두 조건이 모두 참(`True`)일 때만 최종 참 반환 |
| 논리 연산 | `or` | `b or c` | 두 조건 중 하나라도 참(`True`)이면 최종 참 반환 |
| 논리 연산 | `not` | `not b` | 현재 참 또는 거짓 상태를 반대로 뒤집은 값 반환 |

### 3. 연산자 사용 시 주의 사항

#### 구문 제약 특징
* 🔴 **자바와 달리 `++` 또는 `--` 형태의 단항 증감 연산자 사용 불가**
* 문자열과 숫자의 곱셈 연산(`*`) 시 해당 문자열을 숫자 횟수만큼 반복 처리
  
  ex) `"안녕" * 3` =>  `"안녕안녕안녕"`
