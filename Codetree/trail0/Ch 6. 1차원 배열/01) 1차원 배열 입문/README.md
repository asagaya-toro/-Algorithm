### 리스트란?

- 여러 값을 **순서대로** 저장할 수 있는 자료구조
- 서로 다른 자료형을 **한 리스트 안에** 함께 담을 수 있음
- 대괄호 `[]`로 표현하며, 요소는 쉼표로 구분
- 🔴 리스트는 변경 가능한 자료형 

```python
fruits = ["apple", "banana", "cherry"]
mixed = [1, "hello", 3.14, True]
```

### 리스트 생성 & 초기화 방법

```python
# 1. 직접 초기화
nums = [1, 2, 3, 4, 5]

# 2. 빈 리스트 생성
empty = [] # 일반적인 빈 리스트 생성
empty2 = list() # 다른 자료형을 리스트로 변환할 때

# 3. list() 형변환
chars = list("hello")        # ['h', 'e', 'l', 'l', 'o']
from_range = list(range(5))  # [0, 1, 2, 3, 4]

# 4. 리스트 컴프리헨션 (리스트를 한 줄로 간결하게 생성하는 문법) 
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]

# 5. 곱셈으로 초기화 (같은 값으로 채울 때 자주 씀)
zeros = [0] * 5   # [0, 0, 0, 0, 0]
blank = [None] * 3  # [None, None, None]
```

> ⚠️ 2차원 배열 초기화 시 `[[0]*3]*3` 방식은 **같은 객체를 참조**하게 되어 버그 발생 가능  
> → `[[0]*3 for _ in range(3)]` 방식 권장

### 리스트는 변경 가능한(mutable) 자료형

- 생성 후에도 요소를 **추가 / 수정 / 삭제** 할 수 있음
- 반면 튜플 `tuple`은 변경 불가 (immutable)

```python
nums = [1, 2, 3]
nums[0] = 99      # 수정 가능
print(nums)       # [99, 2, 3]
```

### 인덱싱 & 슬라이싱

```python
nums = [10, 20, 30, 40, 50]

# 양수 인덱스 (앞에서부터)
print(nums[0])   # 10
print(nums[2])   # 30

# 음수 인덱스 (뒤에서부터)
print(nums[-1])  # 50  ← 마지막 요소
print(nums[-2])  # 40

# 슬라이싱 [start:end:step]
print(nums[1:3])    # [20, 30]
print(nums[::-1])   # [50, 40, 30, 20, 10]  ← 역순
```

| 인덱스 | `[0]` | `[1]` | `[2]` | `[3]` | `[4]` |
|--------|-------|-------|-------|-------|-------|
| 값     | 10    | 20    | 30    | 40    | 50    |
| 음수   | `[-5]`| `[-4]`| `[-3]`| `[-2]`| `[-1]`|

### `+` 연산자 — 리스트 연결

- 두 리스트를 **이어 붙여** 새 리스트 반환 (원본 변경 없음)

```python
a = [1, 2, 3]
b = [4, 5, 6]
c = a + b
print(c)   # [1, 2, 3, 4, 5, 6]
```

---

### `*` 연산자 — 리스트 반복

- 리스트를 **n번 반복**한 새 리스트 반환

```python
a = [1, 2, 3]
print(a * 3)   # [1, 2, 3, 1, 2, 3, 1, 2, 3]
```

### 주요 메서드 정리

| 메서드 | 설명 | 예시 |
|--------|------|------|
| `.append(x)` | 맨 끝에 요소 추가 | `a.append(4)` |
| `.insert(i, x)` | 인덱스 `i`에 요소 삽입 | `a.insert(1, 99)` |
| `.extend(iterable)` | 다른 리스트를 이어 붙임 (원본 변경) | `a.extend([5, 6])` |
| `.remove(x)` | 값이 `x`인 첫 번째 요소 삭제 | `a.remove(2)` |
| `.pop(i)` | 인덱스 `i` 요소 삭제 후 반환 (기본값: 마지막) | `a.pop()` |
| `.index(x)` | 값 `x`의 인덱스 반환 | `a.index(3)` |
| `.count(x)` | 값 `x`의 개수 반환 | `a.count(1)` |
| `.sort()` | 오름차순 정렬 (원본 변경) | `a.sort()` |
| `.sort(reverse=True)` | 내림차순 정렬 | `a.sort(reverse=True)` |
| `.reverse()` | 리스트 순서 뒤집기 | `a.reverse()` |
| `.copy()` | 얕은 복사본 반환 | `b = a.copy()` |
| `.clear()` | 모든 요소 삭제 | `a.clear()` |
| `len(a)` | 요소 개수 반환 (내장 함수) | `len(a)` |

```python
a = [3, 1, 4, 1, 5, 9, 2, 6]

a.append(7)          # [3, 1, 4, 1, 5, 9, 2, 6, 7]
a.sort()             # [1, 1, 2, 3, 4, 5, 6, 7, 9]
print(a.count(1))    # 2
print(a.pop())       # 9 반환, 리스트에서 제거
```

---

> 💡 `append` vs `extend` 헷갈릴 때  
> - `append([4, 5])` → `[..., [4, 5]]` 리스트 자체가 요소로 들어감  
> - `extend([4, 5])` → `[..., 4, 5]` 요소들이 풀려서 들어감
